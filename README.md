# UN 기구 공개 채용

「국제관계와 국제기구」 4. 국제연맹과 국제연합, 2~3차시용 **개인 활동** 웹 페이지입니다. Zoom 실시간 쌍방향 수업을 기준으로 만들었습니다.

- **2차시 서류 전형**: UN 기구 한 곳을 골라 조사하고 지원서(5문항)를 씁니다.
- **3차시 현장 미션**: 지원한 기구의 신입 직원이 되어 네 가지 위기(거부권, 주권의 벽, 재정 위기, 강대국의 이탈)를 판단하고 근거를 씁니다. 미션마다 국제연맹의 역사와 연결한 ‘역사의 거울’이 나옵니다.
- **마무리**: 판단 성향이 담긴 임명장을 받고, 성찰 두 문항을 써서 최종 제출합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 학생 화면 |
| `teacher.html` | 교사용 학생 기록 보기 (교사 비밀번호 필요) |
| `config.js` | 교사 설정 (기록 저장소 주소) |

## 학생 기록 모으기 (처음 한 번, 약 5분)

학생 기록은 **선생님 구글 계정의 구글 시트**에 저장됩니다. 별도 서버나 비용이 없습니다.

1. [구글 시트](https://sheets.new)를 새로 만들고 이름을 정합니다. (예: UN 채용 학생 기록)
2. 시트 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있던 코드를 모두 지우고 `apps-script/Code.gs` 내용을 붙여 넣습니다.
4. 맨 위 `TEACHER_KEY`의 `"여기에-교사-비밀번호를-쓰세요"`를 선생님만 아는 비밀번호로 바꾸고 저장합니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **배포**를 누르고 권한 승인 창이 나오면 선생님 계정으로 허용합니다.
7. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해 `config.js`의 `API_URL`에 붙여 넣습니다.
   - GitHub 저장소 화면에서 `config.js` → 연필 아이콘 → 붙여 넣기 → Commit changes

이제 학생 화면에 PIN 입력 칸이 생기고, 학생이 쓰는 내용이 몇 초마다 시트의 「학생기록」 탭에 한 학생당 한 줄로 자동 저장됩니다.

### 수업 중 기록 보기

- `teacher.html`(학생 화면 맨 아래 「교사용 진행 안내」에도 링크가 있습니다)에서 교사 비밀번호를 넣으면 반 전체 진행 단계, 미션 진행, 마지막 저장 시각, 학생별 전체 글을 볼 수 있습니다. 30초마다 새로 고쳐지고, 10분 넘게 저장이 없는 학생은 빨간색으로 표시됩니다.
- **엑셀용 CSV 받기**를 누르면 문항별로 열이 나뉜 파일을 받습니다.
- 구글 시트에서 바로 봐도 됩니다.

### 자주 묻는 것

- **학생이 기기를 바꿨어요**: 학번, 이름, 처음 정한 PIN 4자리를 넣으면 이어서 합니다.
- **학생이 PIN을 잊었어요**: 시트에서 그 학생 줄의 ‘PIN 확인값’ 칸을 지우세요. 학생이 새 PIN으로 들어오면 기존 기록을 불러옵니다.
- **학번이나 이름을 잘못 입력했어요**: 다른 사람으로 저장됩니다. 시트에서 잘못 만든 줄을 지우고 바르게 다시 들어오게 하세요.
- **Apps Script 코드를 고쳤어요**: 배포 → 배포 관리 → 연필 → 버전 ‘새 버전’으로 다시 배포해야 반영됩니다. 주소는 그대로입니다.
- **저장소를 설치하지 않으면**: 학생 기록은 학생 기기의 브라우저에만 남습니다. 이때는 최종 제출물을 복사해 내게 하고, `config.js`의 `SUBMIT_URL`에 제출처(구글 설문 등)를 넣으면 「제출하러 가기」 버튼이 생깁니다.

## 고칠 수 있는 곳

- 기구 목록: `index.html`의 `ORGS`
- 미션 내용, 선택지, 게이지 변화: `index.html`의 `MISSIONS`
- 글자 수 기준: 각 입력 칸의 `data-min`

분 단위 진행표와 채점 기준은 학생 화면 맨 아래 「교사용 진행 안내」에 있습니다.
